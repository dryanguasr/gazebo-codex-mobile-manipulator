# Experimento: manipulador móvil ROS 2 + Gazebo

Repositorio local para el experimento técnico solicitado. El paquete `mobile_manipulator` separa descripción Xacro, configuración de control, mundos, lanzamientos, percepción y pruebas.

```bash
source /opt/ros/jazzy/setup.bash
cd ~/proyectos/gazebo-tutorial/gazebo-codex-mobile-manipulator
colcon build --symlink-install
source install/setup.bash
```

La bitácora técnica vive en `docs/experiment_log.md`; no es un tutorial.
