# Grabación interrumpida por encuadre
La cámara cercana, ajustada a la postura antigua, recortaba la parte alta del
gripper recogido. Se canceló de forma controlada durante NAVIGATE; no es una
corrida nominal exitosa ni un fallo de seguimiento. Se conservan datos y video.
La cámara se elevó 10 cm y amplió su campo horizontal de 0,85 a 1,0 rad.
