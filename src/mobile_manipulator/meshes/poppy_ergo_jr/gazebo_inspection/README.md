# Gazebo inspection visuals

Derived from the seven unmodified official Poppy Ergo Jr Collada assets in
../official, pinned to 7eb32bd385afa11dea5e6a6b6a4a86a0243aaa2b.
License: GPL-3.0-only; full license in ../official/LICENSE_GPL-3.0.txt
(installed distributions: ../licenses/official/LICENSE_GPL-3.0.txt).

Generated by scripts/cad/build_gazebo_visuals.py:
- bake all source instance transforms into unique geometry instances;
- provide explicit surface normals and contrasting inspection materials;
- preserve every triangle vertex in evaluated scene coordinates (1e-10 m audit);
- do not modify visual origins, joints, inertia, or collision geometry.

The original files remain the source of truth. Gazebo's loader reused the first
transform for repeated geometry instances in them: in section_4.dae the two
servo bodies became superimposed despite being 40 mm apart in the source CAD.

Colors: fixed jaw green, moving jaw magenta, servo bodies graphite, horns and
fasteners metallic grey; other printed links each have a distinct color.
The full ancestry and hashes are recorded in manifest.json.

Validate with scripts/cad/verify_gazebo_visuals.py. This uses the installed
gz::common::MeshManager and compares every loaded triangle vertex to the source.
